# KKBOX 数据字典 初版

本字典依据各 CSV 的真实表头和少量流式样本建立。类型、取值范围、缺失率和日期边界需在阶段 2 的分块扫描后补全；样本观察不等于全量结论。

## members_v3.csv

| 字段 | 当前推断 | 粒度/用途 | 待核查 |
|---|---|---|---|
| `msno` | 字符串用户键 | 一行一个用户 | 唯一性、空值、版本覆盖 |
| `city` | 城市编码 | 用户属性 | 编码含义与缺失 |
| `bd` | 年龄或年龄编码 | 用户属性 | 异常值、负值、隐私展示范围 |
| `gender` | 性别类别 | 用户属性 | 缺失与编码 |
| `registered_via` | 注册渠道编码 | 用户属性 | 编码说明 |
| `registration_init_time` | `YYYYMMDD` 日期 | 注册日期 | 全量边界 |

## transactions.csv

| 字段 | 当前推断 | 粒度/用途 | 待核查 |
|---|---|---|---|
| `msno` | 字符串用户键 | 交易关联 | 空值与覆盖 |
| `payment_method_id` | 付款方式编码 | 交易维度 | 代码含义 |
| `payment_plan_days` | 计划周期天数 | 交易口径 | 零值/异常 |
| `plan_list_price` | 计划标价 | 金额 | 币种与精度 |
| `actual_amount_paid` | 实际支付金额 | 支付指标 | 退款/撤销解释 |
| `is_auto_renew` | 自动续费标志 | 续费分析 | 取值集合 |
| `transaction_date` | `YYYYMMDD` 日期 | 交易时间 | 全量边界 |
| `membership_expire_date` | `YYYYMMDD` 日期 | 到期时间 | 边界与异常 |
| `is_cancel` | 取消标志 | 取消分析 | 是否即时失效 |

## user_logs.csv

| 字段 | 当前推断 | 粒度/用途 |
|---|---|---|
| `msno` | 字符串用户键 | 用户关联 |
| `date` | `YYYYMMDD` 日期 | 用户日粒度 |
| `num_25`, `num_50`, `num_75`, `num_985`, `num_100` | 播放进度区间计数 | 活跃行为 |
| `num_unq` | 不重复歌曲数或类似行为计数 | 活跃行为，需官方说明确认 |
| `total_secs` | 总时长秒数 | 活跃行为 |

## train.csv

| 字段 | 当前推断 | 用途 |
|---|---|---|
| `msno` | 字符串用户键 | 标签关联 |
| `is_churn` | 竞赛标签 | 仅作为官方标签，不能冒充月度流失 |
