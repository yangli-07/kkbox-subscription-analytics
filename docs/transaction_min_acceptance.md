## 月份与版本规则

- v1 样本交易月份：2015-01 至 2017-02。
- v2 样本交易月份：2015-01 至 2017-03。
- v1/v2 有大量用户重叠，但不能据此证明两版记录可直接相加。
- Excel 输入和月度核对结果按 `source_version` 分开展示；并集用户数只用于覆盖检查，不作为合并后的收入或交易数。
- `actual_amount_paid` 标记为“交易记录金额”；取消记录保留，金额不称为净收入，也不称为 MRR。
