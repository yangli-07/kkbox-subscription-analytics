# 第 2 阶段开发样本

## 抽样配置

- 抽样总体：完整流式读取 `members_v3.csv` 中非空 `msno` 用户键。
- 方法：蓄水池抽样，不按文件前 N 行，不按交易行随机抽样。
- 固定种子：`20261019`
- 目标规模：约 10,000 名用户。
- 抽样后保留：这些用户在 v1/v2 交易与日志中的全部可用历史，不再随机删除交易或日志行。

## 偏差与适用范围

这是从 members_v3 用户总体抽取的开发样本，不是按付款、活跃度、地区或流失标签分层的代表性调查样本。样本可能低估小群体和稀有交易模式，不能直接外推全平台收入、留存或流失率。它适合开发、逐行核对、规则验证和可复现流程测试；正式结论必须注明样本规模、版本和观察窗口。

## 版本处理

输出分别保存为 v1/v2，并保留 `source_version`。当前不直接纵向拼接，也不因文件名带 v2 就覆盖 v1。先比较样本用户的月份、重复记录、覆盖和标签窗口，再决定是否构建派生组合表。

## 生成命令

```text
cd 项目根目录
python3 src/phase2_prepare_sample.py
```

预期输出：`data/processed/sample_users.csv`、四个按版本区分的压缩 CSV、`data/processed/phase2_quality_report.json` 和 `data/processed/sampling_config.json`。失败时保留已完成的阶段 1 结果，不重跑昂贵扫描；检查临时目录和磁盘空间后从未完成的源文件继续。
